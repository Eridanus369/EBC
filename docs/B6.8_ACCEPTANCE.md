#### 2.4.2 40% 不是「还没优化到位」：算术证据

| 量 | 实测值 | 出处 |
|---|---|---|
| 最轻 100 个 `ConstFloat` 对照图 | 1127.9 → 1088.5 ns/帧，降幅 **3.49%** | `/tmp/b662_jit.log:65` |
| 100 节点 `FloatMath` 链（JIT 线自测） | 1680.6 → 1687.3 ns/帧，**−0.40%**（更慢） | `/tmp/b662_jit.log:55-57` |
| 同一 harness 的 D.1 普通图（权威失败批） | **+1.42%** | `/tmp/d1_e2e_out/b662_jit.log:51` |
| 每节点体耗时 | **13.27 ns/节点**（1326.6 ns/帧 ÷ 100） | `/tmp/b662_jit.log:61` |
| 其中主体 | 节点体内 **5 层非内联调用**（`Execute → ReadInputFloat → ReadInput → ctx.Value → KX_RuntimeData::Value`） | `/tmp/b662_jit.log:67-68` |
| 调度层可省部分 | **约 0.4 ns/节点**（`value_nodes` 的 uint32 索引 + `unique_ptr` 间接，约 0.3~0.4 ns/节点） | `/tmp/b662_jit.log:69-70` |
| 最好情况下限 | 约 **3.5%**；多一层虚调用时约 **−1%** | `/tmp/b662_jit.log:71` |

- **算术**：实测 98/100 节点纯值图的内联收益为 **−0.40% ~ +1.42%**（≈ `−0.4% ~ +1.5%`）。
  `40% / 3.49% ≈ 11.46` 倍；`40% / 1.42% ≈ 28.17` 倍。
  `0.3~0.4 ns / 13.27 ns ≈ 2.3%~3.0%`，与 3.49% 的实测上界同量级——内联能拿走的只是调度层，
  节点体那 5 层调用仍在。**40% 与 3.49% 差约 11 倍，属结构性不可达，不是精度问题。**
- 要真正达到 40%，必须「直线特化」：把叶子节点的偏移读写直接展开成直线代码
  （`/tmp/b662_jit.log:72-74`），这会偏离任务书「block 持节点指针、`ExecuteValueOnly` 顺序调用全部」
  的约束，并需重写 Math 语义（除零告警、Pow、类型转换），本次未擅自扩大。
- **口径限定（可复核）**：`3.49%` 出自 `build_linux` 上 100 个 `ConstFloat` 的最轻图；
  当前权威失败批在 `build_clean_verify` 上测得的 `const100` 为 **17.10%**
  （`/tmp/d1_e2e_out/b662_jit.log:55`：1453.4 → 1204.9 ns/帧）。两者构建与场景不同，不可混用；
  即使按较高的 17.10%，距 40% 仍有 **2.34 倍**，不改变「该阈值结构性不可达」的结论。

   逐核频率在 1.1–4.5 GHz 跳变（`/tmp/c4_perf_recheck.log`；分段中位 `482.686 / 313.027`，

2. **绑核反向**：`taskset -c 2` 让 `b661_perf` 从快段 `313 µs` 级劣化到 **552 µs**

   快段样点 `:62`：`best_us_per_1000_frames=313.989`）。绑核不能消除双峰，反而把进程钉在慢态核。
3. **无频率无关计数**：`perf_event_paranoid=4` 且 `CapEff=0000000000000000`（无 `CAP_PERFMON`/`CAP_SYS_ADMIN`），
   `perf stat -e cycles,instructions` 报 `Error: No supported events found.`；`valgrind`、

#### 2.4.4 交错测量（目前对「内联方向」最强的证据）

- 方法：同一会话内 `native → inline_off` 逐对交替，6 对；每对求 `off/native` 比值，
  段漂移在对比值内共模抵消。判据**跑前写死**在脚本头注释：
  `[min(r), max(r)]` 含 1 → `cannot distinguish at this precision`；不含 1 且全部同侧 →
  存在方向效应（`tests/a4_interleave.sh:16-20`）。
- 结果：`RATIOS min=0.9613 median=0.9844 max=1.0212`，`contains1=1`，
  `verdict=cannot-distinguish`（`/tmp/a4_interleave_20261106-001659.log:43-46`）。
- 绝对中位差：`native median=2578.8500`、`off median=2541.7000`，差 **1.44%**
  （`/tmp/a4_interleave_20261106-001659.log:44`）；而批次比较给出的差是 **4.1%**
  （`docs/BENCHMARK_FINAL.md:133` 的 `−4.1%`）。**这证明「内联慢 4%」是段漂移伪装**：
